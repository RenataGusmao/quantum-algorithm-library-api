# Quantum Algorithm Library API

API backend da plataforma Quantum Algorithm Library, desenvolvida para gerenciar dados de algoritmos quânticos, tipos de problema, características, áreas de aplicação, referências e usuários administrativos.

## Stack

- Node.js
- TypeScript
- MongoDB Atlas
- Prisma ORM
- Express.js
- JWT

## Funcionalidades previstas

- Autenticação de usuários administrativos
- Cadastro e edição de algoritmos
- Consulta pública de algoritmos
- Filtros por tipo de problema, características e área de aplicação
- Registro de logs de auditoria
- Estrutura preparada para futura integração com IA
